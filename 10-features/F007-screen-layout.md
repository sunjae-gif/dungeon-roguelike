# F007 화면 구성

## 목적
지금 상황과 위험을 한눈에 알 수 있게 한다.

## 화면 크기와 배치
1. 기준 해상도는 ui.json `baseResolution`(1280×720). 캔버스는 이 크기로 고정한다. 창 크기에 맞춘 자동 확대는 하지 않는다(M5에서 다시 검토).
2. 배치:
   ```
   ┌───────────────────────────┬──────────┐
   │                           │          │
   │   지도 (25×17칸)           │  상태창   │
   │                           │ (300px)  │
   ├───────────────────────────┤          │
   │   메시지 로그 (5줄)         │          │
   └───────────────────────────┴──────────┘
   ```
   - 지도: 왼쪽 위. 보이는 칸 수는 ui.json `viewportTiles`, 칸 크기는 sprites.json `tileSize`.
   - 상태창: 오른쪽. 폭은 ui.json `layout.statusPanelWidth`.
   - 메시지 로그: 지도 아래. 줄 수는 ui.json `layout.messageLogLines`.
   - 정확한 좌표는 위 수치와 `layout.padding`으로 계산한다. 코드에 픽셀 좌표를 직접 쓰지 않는다.

## 카메라
3. 화면은 플레이어를 가운데에 두도록 따라간다.
4. 단, 지도 끝에 가까워지면 카메라는 지도 밖을 보여주지 않도록 멈춘다. 이때 플레이어는 가운데에서 벗어난다.
5. 지도가 보이는 칸 수보다 작은 방향은 지도를 그 방향 가운데에 놓는다.

## 칸 표시
6. 지금 보이는 칸: 원래 색(또는 이미지)으로 그린다.
7. 탐색됨(지금은 안 보임): 원래 그림을 ui.json `fov.exploredBrightness`(0.5) 밝기로 그린다. 그 칸의 몬스터와 아이템은 그리지 않는다. 물체(문, 계단)는 마지막으로 본 모습으로 그린다.
8. 한 번도 안 본 칸: `fov.unexploredColor`(검정)로 칠한다.

## 그림
9. 지도는 탑뷰 격자 픽셀아트다. 픽셀아트는 정수 배율로만 확대하고, 흐리게 보간하지 않는다(`imageSmoothingEnabled = false`).
10. 그리는 순서: 바닥·벽 → 물체(문, 함정, 계단, 상자) → 아이템 → 몬스터 → 플레이어.
11. 바닥·벽·문 그림은 현재 층 테마의 `tiles`(themes.json)에서 id를 찾는다.
12. 모든 그림은 sprites.json의 id로 찾는다. 코드에 이미지 경로를 직접 쓰지 않는다.
13. 이미지 파일이 없거나 불러오기에 실패하면 `fallbackColor` 사각형으로 그린다. 게임은 멈추지 않는다.
14. 캐릭터 이미지는 바라보는 방향(상하좌우)별로 둘 수 있다. 방향 이미지가 없으면 기본 이미지 하나를 쓴다.
15. 이동은 연출 없이 바로 다음 칸에 그린다. 이동 연출은 M5에서 `render/`에만 추가하고, 규칙 코드는 바꾸지 않는다.

## 글자
16. 모든 글자는 ui.json `font`의 한글 픽셀 글꼴(Galmuri11)로 쓴다. 글꼴 파일은 `public/fonts/`에 둔다.
17. 글꼴이 아직 안 불러와졌거나 실패하면 `font.fallback`으로 그린다. 글꼴 로딩을 기다리느라 게임 시작을 막지 않는다.

## 상태창
18. 위에서부터: 현재 층(테마 이름 포함), HP/최대 HP, 공격, 방어, 소모품 목록(번호 포함), 빌드 아이템 목록.
19. HP가 최대의 `lowHpRatio`(30%) 이하이면 HP 글자를 `colors.hpLow`로 바꾼다.
20. 값은 최종 능력치(30-systems/effects.md `getStat`)로 보여준다.
21. 개발자 모드(F012)에서는 맨 아래에 시드를 표시한다.

## 메시지 로그
22. 최근 메시지 5줄. 가장 새 메시지가 맨 위에 있다.

## 이번 버전에서 하지 않는 것
- 스탠딩 일러스트 표시 (M5에서 위치를 정한다. 지금은 자리를 두지 않는다)
- 창 크기에 맞춘 자동 확대
- 이동·공격 애니메이션

## 완료 기준
- [ ] 캔버스 크기가 1280×720이다.
- [ ] 50×30 지도에서 플레이어가 (0, 0) 근처 방에 있을 때 카메라 왼쪽 위가 (0, 0)이다. (지도 밖이 보이지 않는다)
- [ ] 플레이어가 지도 가운데 있을 때 플레이어가 화면 지도 영역의 가운데 칸에 그려진다.
- [ ] 한 번도 안 본 칸은 검정이고, 탐색됨 칸은 보이는 칸보다 어둡다.
- [ ] 탐색됨 칸에 있는 몬스터는 그려지지 않는다.
- [ ] 이미지 파일이 하나도 없어도 게임이 끝까지 플레이된다.
- [ ] sprites.json에 없는 id를 그리려 하면 콘솔에 경고를 남기고 색 사각형으로 그린다.
- [ ] 글꼴 파일이 없어도 글자가 대체 글꼴로 나온다.
- [ ] HP가 바뀌면 같은 턴에 상태창이 갱신된다.
- [ ] 메시지가 6개 이상이면 가장 오래된 것부터 안 보인다.
- [ ] 화면 코드(`render/`)에 픽셀 좌표·색 값이 직접 쓰여 있지 않다. (ui.json, sprites.json에서 읽는다)

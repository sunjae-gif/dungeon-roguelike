# F013 계단과 층 이동

## 목적
계단으로 다음 층에 내려간다. M1에서 지도 생성을 여러 층에 걸쳐 확인하는 데도 쓴다.
(원래 F006에 있던 규칙을 따로 떼어냈다. 게임 오버와 재시작은 F006에 남아 있다.)

## 규칙
1. 1~9층의 계단 칸 위에서 `>` 또는 Enter를 누르면 다음 층으로 간다. 한 턴을 쓴다(turn-order.md `descend`).
2. 새 층은 F001로 새로 만든다. 시드는 rng.md 규칙을 따르므로, 같은 판 시드면 같은 층이 나온다.
3. 층을 내려가도 플레이어의 HP, 소모품, 빌드 아이템은 유지된다. 위치는 새 층의 시작 지점이다.
4. 이전 층의 상태는 버린다. 위층으로 다시 올라가는 기능은 없다.
5. 새 층에 들어가면 phase가 `floorIntro`가 되어 층 번호와 테마 이름을 ui.json `floorIntroMs`(1.5초) 동안 보여준다. 아무 키를 누르면 바로 `playing`으로 넘어간다(game-flow.md).
6. 새 층에 들어가면 시야를 바로 계산한다. 시작 방이 보이는 상태로 시작한다.
7. 계단 칸 위에 올라서면 메시지 로그에 "계단이 있다. >를 눌러 내려간다."를 남긴다.
8. 새 층에 들어가면 메시지 로그에 "N층에 들어섰다."를 남긴다.

## 예외·엣지 케이스
- 계단이 아닌 칸에서 `>`나 Enter를 누르면 아무 일도 없고 턴도 지나가지 않는다.
- 10층에는 계단이 없다(F001). 클리어는 F008이 다룬다.

## 완료 기준
- [ ] 계단에서 `>`를 누르면 floorNumber가 1 늘고 지도가 바뀐다.
- [ ] 계단이 아닌 칸에서 `>`를 누르면 상태가 바뀌지 않는다.
- [ ] 층을 내려간 뒤 HP, 소모품, 빌드 아이템이 같다.
- [ ] 같은 runSeed로 두 번 시작해 3층까지 내려가면 3층 지도가 같다.
- [ ] 4층에 들어가면 theme_2 설정의 지도 크기로 만들어진다.
- [ ] 내려간 직후 phase가 `floorIntro`다.

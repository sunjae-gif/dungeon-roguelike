# F012 개발자 모드

## 목적
플레이어용 기능이 아니라 개발·테스트용이다. 10층 보스를 확인하려고 매번 9층을 내려가지 않게 한다.
`serves`의 P1은 개발 반복을 짧게 한다는 뜻으로 붙였다.

## 규칙
1. 개발 서버(`npm run dev`)에서만 켜진다. 배포 빌드(`npm run build`)에는 코드가 포함되지 않는다(`import.meta.env.DEV`로 분기).
2. `` ` `` (백틱) 키로 개발자 창을 열고 닫는다. 창이 열려 있는 동안 게임 입력은 받지 않는다.
3. 기능:
   | 명령 | 하는 일 |
   |---|---|
   | 시드 표시 | 현재 runSeed를 상태창에 항상 표시 |
   | 시드로 시작 | 시드를 입력해 1층부터 새 판 |
   | 층 이동 | 원하는 층(1~10)으로 바로 이동. HP·아이템 유지 |
   | 지도 공개 | 모든 칸을 탐색됨으로, 숨은 물체·함정을 표시 |
   | 무적 | 플레이어가 피해를 받지 않음 |
   | 아이템 생성 | items.json id를 입력해 인벤토리 또는 빌드에 추가 |
   | 상태 내보내기 | 현재 RunState를 JSON으로 복사 (버그 보고용) |
   | 상태 불러오기 | JSON을 붙여 넣어 그 상태에서 이어하기 |
4. 개발자 모드로 바뀐 상태도 game-state.md 구조를 따른다. 별도 필드가 필요하면 `RunState.dev`(선택 필드) 하나에 모은다.

## 완료 기준
- [ ] `npm run build` 결과물에 개발자 모드 문자열이 없다.
- [ ] 층 이동으로 10층에 가면 보스방이 있는 층이 생성된다.
- [ ] 상태 내보내기 → 불러오기 후 화면과 상태가 같다.

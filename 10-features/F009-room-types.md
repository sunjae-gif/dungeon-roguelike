# F009 방 종류

## 목적
층마다 방 구성이 달라서, 어떤 방을 먼저 뒤질지·위험을 감수할지 고르게 한다.

## 방 종류
| id | 이름 | 하는 일 |
|---|---|---|
| `start` | 시작방 | 플레이어 시작 지점. 층마다 1개. 몬스터·함정 없음 |
| `stairs` | 계단방 | 계단이 있는 방. 1~9층에 1개 |
| `boss` | 보스방 | 10층에 1개(F008) |
| `normal` | 일반방 | 몬스터와 바닥 아이템이 나온다 |
| `treasure` | 보물상자방 | 상자가 있다. 열면 아이템을 얻는다 |
| `secret` | 비밀방 | 입구가 숨겨져 있다. 찾으면 보상이 있다 |
| `puzzle` | 퍼즐방 | 퍼즐을 풀면 보상이 나온다 |

## 규칙
1. F001이 만든 방 목록에서 먼저 `start`, `stairs`(또는 `boss`)를 정한다. 이 방들은 구조용 방이라 다른 종류(보물상자방 등)를 겸하지 않는다.
2. 구조용 방을 뺀 나머지 방만 rooms.json의 가중치(`weight`)에 따라 무작위로 종류를 정한다. 테마별로 가중치를 바꿀 수 있다(themes.json `roomWeights`).
3. 종류마다 한 층에 나올 수 있는 최소·최대 개수(rooms.json `minPerFloor`, `maxPerFloor`)를 지킨다.
4. 비밀방은 통로로 연결하지 않는다. 다른 방이나 통로와 맞닿은 벽 1칸을 "숨은 벽"으로 만들어 입구로 쓴다(F010).
5. 같은 시드면 같은 방 종류 배치가 나온다.

## 보물상자
- 상자와 보상 규칙은 F005가 정한다(M3). F005는 "층마다 보물상자방 최소 1개"만 구현하고, 이 문서는 M4에서 가중치로 더 만드는 것(최대 2개)을 맡는다. rooms.json `treasure`의 `minPerFloor`를 1로 바꾼다(10층 제외).
- 비밀방 보상: 희귀 빌드 아이템 둘 중 하나. 퍼즐방 보상: 빌드 아이템 셋 중 하나 (F005 규칙 12)

## 예외·엣지 케이스
- 방 개수가 모자라 최소 개수를 채울 수 없으면 `normal`을 줄여서 채운다. 그래도 안 되면 최소 개수 조건을 건너뛰고 경고 로그를 남긴다.

## 완료 기준
- [ ] 모든 층에 `start`가 정확히 1개 있다.
- [ ] 1~9층에 `stairs`가, 10층에 `boss`가 정확히 1개 있다.
- [ ] 시드 1000개로 생성했을 때 종류별 개수가 최소·최대 범위를 벗어나지 않는다.
- [ ] 시드 1000개로 생성했을 때 종류별 비율이 가중치 비율과 ±5%p 안에서 맞는다.
- [ ] 비밀방의 바닥 칸은 숨은 벽을 열기 전에는 시작 지점에서 닿을 수 없다.

## 미결정 사항
- [ ] 비밀방 찾는 방법: 숨은 벽에 부딪히면 일정 확률로 발견 / 탐색 키로 주변 수색 / 특정 아이템이 있으면 보임
- [ ] 퍼즐 종류: 첫 버전에 넣을 퍼즐 1~2개 (예: 발판을 모두 밟기, 상자를 밀어 스위치에 올리기, 정해진 순서로 레버 당기기)
- [ ] 퍼즐을 실패하면 벌칙이 있는가? (함정 발동, 몬스터 등장)
- [ ] 보물상자를 지키는 몬스터가 있는가? 미믹(상자로 위장한 몬스터)이 있는가?
- [ ] 몬스터방·상점방·회복방 같은 다른 종류를 넣는가?
- [ ] **HP 회복 이벤트·환경** (예: 회복 샘, 쉼터, 제단). 지금 회복 수단은 물약뿐이다(F003). 방 종류로 넣을지, 물체(F010)로 넣을지 함께 정한다.

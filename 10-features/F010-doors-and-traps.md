# F010 문과 함정

## 목적
문은 시야를 끊어 "저 너머에 뭐가 있을까"를 만든다. 함정은 **숨은 위험이 아니라 보이는 지형**이다. 피해 가거나, 몬스터를 밀어 넣거나, 유인하는 데 쓴다(P2). 보이지 않는 함정에 당하는 일은 없다(P4).

## 정해진 것
- **함정은 처음부터 보인다.** 숨은 함정, 함정 찾기(수색)는 없다.
- 몬스터도 함정을 밟으면 발동한다. 단, 몬스터는 길을 찾을 때 함정을 피한다(돌아갈 길이 있을 때).
- 잠긴 문과 열쇠는 없다(되돌아가는 길이 생겨 판이 길어진다, P1).

## 물체 종류
| type | 이름 | state | blocksMove | blocksSight |
|---|---|---|---|---|
| `door` | 문 | `{ open: false }` | 닫혀 있으면 true (부딪히면 열림) | 닫혀 있으면 true |
| `trap` | 함정 | `{ spent: false }` | false (밟으면 발동) | false |

숨은 벽(`hiddenWall`)은 비밀방의 입구라서 F009가 다룬다.

## 문
1. 문은 방과 통로가 만나는 칸에 생긴다. 생기는 확률은 테마의 `doorChance`. 보스방(봉인이 대신함), 비밀방(숨은 벽이 대신함) 입구에는 문을 두지 않는다.
2. 닫힌 문으로 이동하면 문이 열리고 그 개체는 제자리에 있다. 한 턴을 쓴다.
3. 열린 문은 다시 닫히지 않는다.
4. 몬스터도 문을 연다(문 열기가 그 몬스터의 행동). 원거리 몬스터의 사격선과 몬스터 시야는 닫힌 문에 막힌다.
5. 메시지: 플레이어가 열면 "문을 열었다." 몬스터가 연 문이 플레이어 시야에 있으면 "{몬스터}이(가) 문을 열었다."

## 함정 배치
6. 함정은 **방 안의 바닥 칸에만** 놓는다. 통로에는 놓지 않는다. (폭 1칸 통로에 놓이면 피할 길이 없다)
7. 다음 칸에는 놓지 않는다: 방 입구 칸과 그 상하좌우, 물체·개체·바닥 아이템이 있는 칸.
8. 다음 방에는 놓지 않는다: 시작방, 계단방, 보스방, 비밀방, 퍼즐방, 샘방(F009).
9. 개수와 종류는 테마의 `trapCount`, `trapTypes`. 종류는 같은 확률로 고른다. `objects` 난수 흐름을 쓴다.
10. 함정은 방 안에서 돌아갈 길을 막지 않게 놓는다: 함정을 놓은 뒤에도 그 방의 모든 입구끼리, 그리고 방 안의 물체(상자 등)까지 함정을 밟지 않고 갈 수 있어야 한다. 막으면 그 자리에는 놓지 않는다.

## 함정 발동
11. 개체가 함정 칸에 들어가면(걸어서, 밀려서) 발동한다. 효과는 traps.json의 `effects`로, `self`는 밟은 개체다(effects.md). 발동 뒤 `onTrapTriggered`.
12. 함정은 밟을 때마다 다시 발동한다. `once: true`인 함정은 한 번 발동하면 `spent`가 되어 사라진다(그림도 지운다).
13. 함정 피해는 "공격이 아닌 피해"다(effects.md 4절). 함정으로 죽은 몬스터는 처치 수에 들어가고 `onKill`은 없다. 플레이어가 죽으면 `killedBy`는 함정 id, 문구는 "{함정 이름}(으)로 쓰러졌다."
14. 메시지: "{개체}이(가) {함정 이름}을(를) 밟았다!" (플레이어면 "{함정 이름}을(를) 밟았다!"). 몬스터의 경우 플레이어 시야 안일 때만.

## 함정 종류

| id | 이름 | 효과 | once | 나오는 테마 |
|---|---|---|---|---|
| `spike` | 가시 함정 | 피해 4 | 아니오 | 1, 2, 3 |
| `poison_gas` | 독 가스 함정 | 3턴 중독 | 아니오 | 3 |
| `alarm` | 경보 함정 | 반경 12 안 몬스터가 이 칸으로 모여듦 | 예 | 2, 3 |

```json
{ "id": "spike", "name": "가시 함정", "sprite": "trap_spike",
  "effects": [ { "type": "damage", "target": "self", "amount": 4 } ] }
{ "id": "poison_gas", "name": "독 가스 함정", "sprite": "trap_gas",
  "effects": [ { "type": "applyStatus", "target": "self", "status": "poison", "turns": 3 } ] }
{ "id": "alarm", "name": "경보 함정", "sprite": "trap_alarm", "once": true,
  "effects": [ { "type": "alarm", "radius": 12 } ] }
```

- `alarm` 효과(effects.md에 추가): 함정 칸에서 4방향 거리 `radius` 안의 모든 몬스터(벽 무시)에게 `ai.lastSeenPlayer`를 그 칸으로 정한다. 매복 몬스터는 깨우지 않는다. 메시지 "경보가 울렸다! 발소리가 다가온다."
- 면역(`status:poison`)이 있으면 독 가스는 통하지 않는다(정화의 부적).

## 다른 기능에 주는 변경 (이 문서를 구현할 때 함께 바꾼다)
15. **몬스터 길 찾기(F004 규칙 13):** 먼저 함정 칸을 지나지 않는 최단 경로를 찾는다. 그런 경로가 없을 때만 함정을 지나는 경로를 쓴다. 문은 닫혀 있어도 경로에 넣는다(열고 지나간다).
16. **원거리 몬스터의 사격 위치(F014)**, **도망 칸 고르기(F014)**: 함정 칸은 후보에서 뺀다.
17. **밀쳐내기(effects.md):** 밀려 들어간 칸에 함정이 있으면 발동한다(이미 정해진 규칙). 몬스터는 함정을 피해 다니므로, 함정을 이용하는 주된 방법이 된다.
18. **키 누르고 있기(F002):** 반복 이동 중 다음 칸이 함정이면 그 칸으로 가지 않고 반복을 멈춘다. 일부러 밟으려면 키를 다시 눌러야 한다. 문 앞에서도 멈춘다(문 열기는 반복하지 않는다).
19. **보스(F008):** 보스방에는 함정이 없다.

## 화면
- 함정은 sprites.json 그림(없으면 `fallbackColor`)으로 바닥 위에 그린다. 탐색됨 칸의 함정도 어둡게 그린다.
- sprites.json에 `trap_gas`, `trap_alarm`, `door_open_*`(테마별 열린 문) 추가.

## 완료 기준
- [ ] 닫힌 문 너머 칸은 보이지 않고, 원거리 몬스터도 닫힌 문 너머로 쏘지 않는다.
- [ ] 닫힌 문으로 이동하면 문이 열리고, 위치는 그대로, 턴 수가 1 늘어난다. 몬스터도 문을 연다.
- [ ] 함정은 처음부터 보인다.
- [ ] 시드 1000개로 생성했을 때 함정이 통로, 입구 주변, 금지된 방에 없다.
- [ ] 시드 1000개로 생성했을 때 모든 방에서 입구끼리, 입구에서 상자까지 함정을 밟지 않는 길이 있다.
- [ ] 가시 함정을 밟으면 HP −4, 다시 밟으면 또 −4.
- [ ] 경보 함정을 밟으면 반경 12 안 몬스터가 그 칸으로 오고, 함정은 사라진다.
- [ ] 정화의 부적이 있으면 독 가스 함정을 밟아도 중독되지 않는다.
- [ ] 함정 옆을 지나 플레이어에게 오는 몬스터는 돌아갈 길이 있으면 함정을 밟지 않는다.
- [ ] 전투 망치로 몬스터를 가시 함정 위로 밀면 함정이 발동한다.
- [ ] 함정으로 몬스터가 죽으면 처치 수가 늘고, 전사의 문장은 발동하지 않는다.
- [ ] 키를 누르고 이동하다 다음 칸이 함정이면 그 앞에서 멈춘다.

# F011 층 테마

## 목적
3층마다 분위기가 바뀌어 "깊이 내려왔다"는 느낌을 준다. 최종보스층은 앞의 어느 테마와도 다르게 만든다.

## 테마 구성
| 테마 id | 층 | 성격 |
|---|---|---|
| `theme_1` | 1~3층 | 입문. 약한 몬스터, 함정 적음 |
| `theme_2` | 4~6층 | 중간 |
| `theme_3` | 7~9층 | 어려움 |
| `theme_boss` | 10층 | 최종보스층. 앞 세 테마와 완전히 다른 분위기 |

## 규칙
1. 층 번호로 테마를 찾는다. 어느 층이 어느 테마인지는 themes.json `floors`가 정한다.
2. 테마가 정하는 것: 지도 크기, 타일 그림(바닥·벽·문), 나오는 몬스터, 아이템 수, 방 종류 가중치, 문 확률, 함정 개수와 종류.
3. 코드는 테마 id로 분기하지 않는다. 모든 차이는 themes.json 값으로만 만든다. 새 테마를 추가할 때 코드를 고치지 않아도 되게 한다.
4. 테마가 바뀌는 층(4층, 7층, 10층)에 처음 들어가면 메시지 로그에 테마 이름을 띄운다.

## 완료 기준
- [ ] 1, 3층은 theme_1, 4층은 theme_2, 10층은 theme_boss 설정으로 생성된다.
- [ ] 각 층의 몬스터가 그 테마의 `monsterTypes` 안에서만 나온다.
- [ ] themes.json에 테마를 하나 더 추가하고 floors를 바꾸면 코드 수정 없이 반영된다.

## 미결정 사항
- [ ] 테마 4개의 이름과 분위기 (예: 버려진 지하묘지 → 버섯 동굴 → 용암 광산 → 별이 보이는 공허)
- [ ] 테마마다 고유 몬스터·고유 함정·고유 방을 넣을지
- [ ] 10층의 "완전히 다른 분위기"가 그림만 다른 것인지, 지도 구조도 다른 것인지 (예: 방 여러 개 대신 큰 공간 하나)

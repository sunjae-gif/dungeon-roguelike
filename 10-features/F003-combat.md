# F003 전투

## 목적
몬스터와 부딪히는 순간마다 싸울지 피할지 고민하게 한다.

## 정해진 것
- 레벨과 경험치는 없다. 몬스터를 쓰러뜨려도 능력치가 오르지 않는다.
- 캐릭터의 강함은 모은 아이템으로만 바뀐다(F005).

## 규칙 (임시안, 확정 전)
1. 공격은 상하좌우로 인접한 칸의 대상에게 한다. 플레이어는 몬스터 방향으로 이동해서 공격한다.
2. 피해 = 공격자 `attack` − 방어자 `defense`. 최소 피해는 1이다. 능력치는 보정이 반영된 최종값을 쓰고, 계산 순서는 30-systems/effects.md "피해 처리 순서"를 따른다.
3. HP가 0 이하가 되면 죽는다. 몬스터가 죽으면 지도에서 사라진다. 플레이어가 죽으면 게임 오버(F006).
4. 공격도 한 턴을 쓴다.
5. 전투 결과는 메시지 로그에 남는다. 예: "고블린에게 3 피해를 입혔다."

## 예외·엣지 케이스
- 같은 턴에 플레이어와 몬스터가 서로를 죽이는 일은 없다. 턴 순서(30-systems/turn-order.md)대로 먼저 행동한 쪽이 먼저 계산된다.

## 완료 기준
- [ ] 공격 5, 방어 2일 때 피해는 3이다.
- [ ] 공격 2, 방어 5일 때 피해는 1이다.
- [ ] HP가 0이 된 몬스터는 다음 턴에 지도에 없다.
- [ ] 플레이어 HP가 0이 되면 게임 오버 상태가 된다.
- [ ] 몬스터를 쓰러뜨려도 플레이어 능력치가 변하지 않는다.

## 미결정 사항
- [ ] 능력치 종류: 공격·방어·HP 외에 무엇이 있는가? (빌드 다양성의 재료가 된다. F005와 함께 결정)
- [ ] 명중률·회피·치명타 같은 무작위 요소를 넣는가? (P4와 부딪힐 수 있음)
- [ ] 아이템이 전투 규칙 자체를 바꾸는가? (예: 공격 시 흡혈, 2칸 앞 공격)

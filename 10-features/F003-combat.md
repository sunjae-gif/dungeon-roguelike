# F003 전투

## 목적
몬스터와 부딪히는 순간마다 싸울지 피할지 고민하게 한다.

## 정해진 것
- 레벨과 경험치는 없다. 몬스터를 쓰러뜨려도 능력치가 오르지 않는다.
- 캐릭터의 강함은 모은 아이템으로만 바뀐다(F005).
- 능력치는 `maxHp`, `attack`, `defense`, `sightRadius` 네 가지다. 빌드에 필요한 능력치는 F005를 설계할 때 effects.md 표에 추가한다.
- **기본 전투에는 무작위 요소가 없다.** 명중·회피·치명타 확률이 없어서, 같은 능력치끼리 싸우면 결과가 항상 같다(P4). 무작위는 아이템 효과의 `chance`로만 들어온다(effects.md).
- HP 회복 수단은 지금은 물약뿐이다(F005). 자연 회복, 층 이동 시 회복은 없다. 회복 이벤트·환경은 나중에 따로 추가한다(F009 미결정 사항).

## 규칙
1. 공격은 상하좌우로 인접한 칸의 대상에게 한다. 플레이어는 몬스터 방향으로 이동해서 공격한다.
2. 피해 = 공격자 `attack` − 방어자 `defense`. 최소 피해는 1이다. 능력치는 보정이 반영된 최종값(`getStat`)을 쓰고, 계산 순서는 30-systems/effects.md "피해 처리 순서"를 따른다.
3. HP가 0 이하가 되면 죽는다. 몬스터가 죽으면 지도에서 사라지고 `runStats.kills`가 1 는다. 플레이어가 죽으면 게임 오버(F006).
4. 공격도 한 턴을 쓴다.
5. 전투 결과는 메시지 로그에 남는다.
   | 상황 | 문구 |
   |---|---|
   | 플레이어가 공격 | "{몬스터}에게 {피해} 피해를 입혔다." |
   | 몬스터가 공격 | "{몬스터}에게 {피해} 피해를 받았다." |
   | 몬스터 처치 | "{몬스터}을(를) 쓰러뜨렸다." |
   | 플레이어 사망 | "{몬스터}에게 쓰러졌다." |

## 예외·엣지 케이스
- 같은 턴에 플레이어와 몬스터가 서로를 죽이는 일은 없다. 턴 순서(30-systems/turn-order.md)대로 먼저 행동한 쪽이 먼저 계산된다.
- 아이템이 전투 규칙 자체를 바꾸는 경우(예: 2칸 앞 공격)는 F005 설계 때 정한다. M2에서는 고려하지 않는다.

## 완료 기준
- [ ] 공격 5, 방어 2일 때 피해는 3이다.
- [ ] 공격 2, 방어 5일 때 피해는 1이다.
- [ ] 같은 상태에서 같은 공격을 1000번 계산하면 피해가 모두 같다.
- [ ] HP가 0이 된 몬스터는 다음 턴에 지도에 없고, kills가 1 늘었다.
- [ ] 플레이어 HP가 0이 되면 게임 오버 상태가 된다.
- [ ] 몬스터를 쓰러뜨려도 플레이어 능력치가 변하지 않는다.
- [ ] 몬스터 방향으로 이동 입력을 하면 위치는 그대로이고 몬스터 HP가 준다.

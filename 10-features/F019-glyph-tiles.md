# F019 글자 타일과 보기 정보

## 목적
그림이 없는 동안 색 사각형만으로는 "저게 무엇인지" 알 수 없다(2026-10-28 직접 플레이 피드백). 그림이 들어오기 전까지 **글자로 무엇인지 보여 주고**, 그림이 들어온 뒤에도 **마우스를 올리거나 상태창을 보면 이름을 알 수 있게** 한다(P4: 위험은 미리 보인다).

## 1. 글자 타일 (그림이 없을 때)
1. 그림 파일이 없는 스프라이트 중 **개체·물체·바닥 아이템**은 색 사각형 대신 글자를 그린다. 바닥과 벽은 지금처럼 색 사각형으로 둔다.
2. 글자와 색은 sprites.json의 `glyph`, `glyphColor`(없으면 `fallbackColor`)로 정한다. 그림 파일이 생기면 자동으로 그림이 대신 그려진다(코드 수정 없음).
3. 글자는 칸 가운데에 Galmuri11로, ui.json `glyph.fontSize`(22px, 글꼴의 정수 배)로 그린다. 바닥 색과 섞이지 않게 1px 어두운 테두리(`glyph.outlineColor`)를 두른다.
4. 바닥 칸에는 가운데에 희미한 점을 찍는다(`colors.floorDot`). 몇 칸 떨어져 있는지 세기 쉬워진다. 그림 파일이 있는 바닥에는 찍지 않는다.
5. 탐색됨(지금은 안 보임) 칸의 글자도 F007 규칙대로 어둡게 그린다. 몬스터는 그리지 않는다.

## 2. 마우스로 보기
6. 마우스를 지도 칸 위에 올리면 커서 옆에 작은 설명 상자를 띄운다. 클릭은 아무것도 하지 않는다(게임은 키보드로만 조작한다).
7. 지금 보이는 칸: 그 칸에서 가장 위에 그려진 것(개체 → 아이템 → 물체 → 칸)의 이름과 한 줄 설명.
8. 탐색됨 칸: 칸과 물체만 (몬스터·아이템 정보는 주지 않는다). 한 번도 안 본 칸: 아무것도 띄우지 않는다.
9. 설명 내용:
   | 대상 | 보여 주는 것 |
   |---|---|
   | 몬스터 | 이름 + 행동 종류 한 단어. 예: "고블린 궁수 · 원거리". **능력치 숫자는 보여 주지 않는다**(F004) |
   | 바닥 아이템 | 이름 + `description` |
   | 함정 | 이름 + 효과. 예: "가시 함정 · 밟으면 피해 4" (traps.json `description` 추가) |
   | 물체 | 이름 + 쓰는 법. 예: "상자 · 그쪽으로 이동해 연다" (labels.json) |
   | 플레이어 | "당신" |
   | 바닥·벽 | 표시 안 함 |
10. 설명 상자는 연출처럼 `render/`에만 있다. 턴과 상태를 바꾸지 않는다.

## 3. 상태창 "보이는 것" 목록
마우스를 쓰지 않는 사람을 위해 같은 정보를 상태창에도 보여 준다.
11. 상태창의 빌드 아이템 목록 아래에 **"보이는 것"** 칸을 둔다.
12. 지금 시야 안에 있는 몬스터·바닥 아이템·함정·상자·샘·계단을 글자(또는 그림)와 이름으로, 플레이어에게 가까운 순서로 최대 `ui.json visibleList.max`(6)개 보여 준다. 같은 종류가 여럿이면 "고블린 ×2"처럼 묶는다.
13. 칸이 모자라면 몬스터를 먼저 보여 준다.

## 함께 고칠 것
- 메시지의 받침 조사: "고블린이(가) 보인다"처럼 나오는 곳을 "을/를"과 같은 방식으로 받침에 맞게 고른다(이/가, 은/는, 와/과, 으로/로). 문구 템플릿의 `이(가)`, `(으)로` 같은 표기를 모두 대상으로 한다.

## 완료 기준
- [ ] 그림 파일이 없을 때 고블린은 초록 "고", 플레이어는 노란 "@"로 그려진다.
- [ ] sprites.json의 어떤 항목에 그림 파일을 넣으면, 그 항목만 글자 대신 그림으로 바뀐다.
- [ ] 바닥에 희미한 점이 찍힌다. 그림이 있는 바닥에는 찍히지 않는다.
- [ ] 보이는 몬스터 위에 마우스를 올리면 "이름 · 행동 종류"가 뜨고, 능력치 숫자는 없다.
- [ ] 탐색됨(안 보임) 칸에 마우스를 올리면 몬스터 정보가 뜨지 않는다.
- [ ] 상태창 "보이는 것"에 시야 안 대상이 가까운 순서로 최대 6개, 같은 종류는 묶여서 나온다.
- [ ] "고블린이 보인다.", "가시 함정으로 쓰러졌다."처럼 조사가 받침에 맞게 나온다.
- [ ] 마우스를 움직여도 턴 수와 상태가 바뀌지 않는다.

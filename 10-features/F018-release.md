# F018 공개 준비

## 목적
링크 하나로 누구나 브라우저에서 바로 해 볼 수 있게 한다. 처음 하는 사람도 설명 없이 조작을 알 수 있어야 한다(P2).

## 조작 안내 (도움말)
지금은 조작법을 알 방법이 없다. 화면에 조작 안내를 넣는다.
1. 타이틀 화면 아래쪽에 한 줄: "방향키/WASD 이동 · Space 쉬기 · 1~9 아이템 · > 내려가기 · ? 도움말"
2. `?` 키(또는 H)로 어느 화면에서든 도움말 창을 열고 닫는다. 열려 있는 동안 게임 입력은 받지 않고 턴도 지나지 않는다. 개발자 창(F012)처럼 phase가 아니라 겹쳐 뜨는 창이다.
3. 도움말 내용:
   | 항목 | 내용 |
   |---|---|
   | 조작 | 이동, 공격(몬스터 쪽으로 이동), 쉬기, 아이템 사용, 내려가기, 상자·문·샘·레버(그쪽으로 이동) |
   | 목표 | 10층의 심연의 왕을 쓰러뜨린다 |
   | 알아두기 | 함정은 보인다 / 막다른 길 끝 벽 옆에서 쉬면 숨은 통로를 찾는다 / 레벨은 없고 상자에서 고른 아이템이 강함이다 |
4. 처음 게임을 시작하면(브라우저에 기록이 없으면) 1층 floorIntro 뒤에 도움말 창을 한 번 자동으로 띄운다. 기록은 `localStorage`의 값 하나만 쓰고, 읽기·쓰기가 실패해도 게임은 그대로 돈다.
5. 키 배치와 도움말 문구는 `20-data/keybindings.json`에 모은다(코드에 키 이름을 흩어 쓰지 않는다). 지금 코드에 흩어진 키 처리를 이 파일을 읽도록 바꾼다.

```json
{
  "_note": "키 배치와 도움말 문구(F018). key 값은 KeyboardEvent.key.",
  "bindings": [
    { "action": "moveUp",    "keys": ["ArrowUp", "w", "W"],    "label": "↑ / W" },
    { "action": "moveDown",  "keys": ["ArrowDown", "s", "S"],  "label": "↓ / S" },
    { "action": "moveLeft",  "keys": ["ArrowLeft", "a", "A"],  "label": "← / A" },
    { "action": "moveRight", "keys": ["ArrowRight", "d", "D"], "label": "→ / D" },
    { "action": "rest",      "keys": [" "],                    "label": "Space" },
    { "action": "descend",   "keys": [">", "Enter"],           "label": "> / Enter" },
    { "action": "help",      "keys": ["?", "h", "H"],          "label": "? / H" }
  ],
  "helpSections": [ "…위 표의 문구…" ]
}
```

## 배포
6. **배포 위치: Cloudflare Pages (무료).** 저장소가 비공개라 GitHub Pages는 무료 요금제에서 쓸 수 없다(GitHub Pro 필요). Cloudflare Pages는 무료로 비공개 저장소를 연결할 수 있고, 정적 사이트의 요청·전송량 제한이 없으며, 상업적 이용도 막지 않는다.
7. 설정: GitHub 저장소 연결, 빌드 명령 `npm run build`, 출력 폴더 `dist`, 배포 브랜치 `main`. `main`에 push할 때마다 자동으로 다시 배포된다.
8. 배포 빌드에는 개발자 모드(F012)와 시뮬레이터(F017)가 들어가지 않는다(이미 완료 기준으로 있음).
9. 버전: ui.json `title.version`을 공개할 때 `1.0.0`으로 올린다. 이후 고칠 때마다 올린다.
10. **사용자가 할 일:** Cloudflare 계정 만들기 → Pages에서 저장소 연결(위 설정) → 나온 주소를 progress.md에 적어 달라고 Claude Code에 알려 주기. 계정 연결은 Claude Code가 대신할 수 없다.

- [ ] 1층부터 10층까지 직접 끝까지 한 판 해 봤다 (클리어 또는 게임 오버)
- [ ] F017 보고서의 ⚠️ 항목을 확인하고, 남겨 둘 것은 이유를 적었다
- [ ] 브라우저 콘솔에 오류가 없다 (Chrome, Firefox 최신)
- [ ] 1366×768, 1920×1080 창에서 화면이 깨지지 않는다
- [ ] 그림 파일이 없는 자리는 색 사각형으로 나온다 (그림은 공개 뒤에도 계속 추가할 수 있다)
- [ ] Galmuri 글꼴 라이선스 파일(OFL.txt)이 함께 배포된다
- [ ] asset-list.md의 공개 에셋·생성 이미지 출처와 라이선스가 적혀 있다

## 완료 기준
- [ ] 타이틀에 조작 안내 한 줄이 있다.
- [ ] `?`로 도움말이 열리고 닫히며, 열려 있는 동안 턴이 지나지 않는다.
- [ ] 처음 시작할 때 한 번만 도움말이 자동으로 뜬다. `localStorage`를 막아도 게임이 돈다.
- [ ] 코드의 키 처리가 keybindings.json을 읽는다. 파일에서 키를 바꾸면 코드 수정 없이 반영된다.
- [ ] `npm run build` 결과물(`dist`)을 정적 서버로 열면 게임이 처음부터 끝까지 돈다.
- [ ] 배포 주소가 progress.md에 적혀 있다 (사용자가 Cloudflare를 연결한 뒤).

# F006 게임 종료와 재시작

## 목적
한 판의 끝을 분명하게 만들고, 끝난 뒤 바로 다시 시작하게 한다.
층 이동은 F013으로 분리했다.

## 규칙
1. 플레이어 HP가 0이 되면 게임 오버 화면을 띄운다. 도달한 층, 쓰러뜨린 몬스터 수, 턴 수를 보여준다.
2. 10층의 최종보스를 쓰러뜨리면 클리어 화면을 띄운다(F008). 같은 정보를 보여준다.
3. 게임 오버·클리어 화면에서 R을 누르면 새 시드로 1층부터 다시 시작한다. Esc를 누르면 타이틀로 간다.

## 완료 기준
- [ ] HP가 0이 된 턴이 끝나면 게임 오버 상태가 된다.
- [ ] 최종보스가 죽으면 클리어 상태가 된다.
- [ ] 재시작하면 층 1, HP 최대, 아이템 없음, 새 runSeed.

# F006 게임 종료와 재시작

## 목적
한 판의 끝을 분명하게 만들고, 끝난 뒤 바로 다시 시작하게 한다.
층 이동은 F013으로 분리했다.

## 규칙
1. 플레이어 HP가 0이 되면 게임 오버 화면을 띄운다. 도달한 층, 쓰러뜨린 몬스터 수, 턴 수, 시드, 쓰러뜨린 몬스터 이름("{몬스터}에게 쓰러졌다")을 보여준다.
2. 10층의 최종보스를 쓰러뜨리면 클리어 화면을 띄운다(F008). 같은 정보를 보여준다. **클리어 판정은 F008이 확정될 때 구현한다.** M2에서는 게임 오버만 만든다.
3. 게임 오버·클리어 화면에서 R을 누르면 새 시드로 1층부터 다시 시작한다. Esc를 누르면 타이틀로 간다.

## 이번 버전에서 하지 않는 것
- 이어하기(브라우저를 닫았다 열었을 때 진행 중인 판 복구). 상태는 JSON으로 저장되는 구조라 나중에 추가하기 쉽다(game-state.md).
- 기록 저장(최고 도달 층 등)

## 완료 기준
- [ ] HP가 0이 된 턴이 끝나면 phase가 `gameOver`다.
- [ ] 게임 오버 화면에 도달 층, 처치 수, 턴 수, 시드가 나온다.
- [ ] 재시작하면 층 1, HP 최대, 아이템 없음, 새 runSeed.

## 미결정 사항
없음.

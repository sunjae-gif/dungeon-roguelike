# 아트 가이드

그림은 두 종류다. 만드는 방법과 규격이 다르므로 섞지 않는다.
모든 그림은 미리 만들어 `public/assets/`에 넣고, `20-data/sprites.json`에 등록한다.

## 1. 인게임 픽셀아트

지도 타일, 캐릭터, 몬스터, 아이템, 상자·함정 같은 물체.

| 항목 | 규격 |
|---|---|
| 원본 크기 | 16×16 픽셀 (sprites.json `sourcePixelSize`) |
| 화면 크기 | 32×32 픽셀 (`tileSize`). 원본을 2배 정수 확대 |
| 형식 | PNG. 캐릭터·물체는 배경 투명, 바닥·벽 타일은 불투명 |
| 확대 | 최근접 이웃(nearest neighbor)만. 흐리게 보간하지 않는다 |
| 위치 | `assets/tiles/`, `assets/chars/`, `assets/objects/`, `assets/items/` |
| 파일 이름 | sprites.json의 id와 같게. 방향 이미지는 `id_up.png`처럼 |

### 일관성 규칙
- 테마마다 색 팔레트를 하나 정하고, 그 테마의 타일은 그 팔레트 안에서만 쓴다.
- 캐릭터 외곽선 색과 두께(1px)를 통일한다.
- 광원 방향을 하나로 통일한다 (예: 왼쪽 위).

### 이미지 생성으로 픽셀아트를 만들 때 주의
생성형 이미지는 "픽셀아트처럼 보이는" 그림을 주지만 실제 격자에 맞지 않는 경우가 많다.
생성 후 16×16으로 줄이고, 색 수를 팔레트에 맞춰 줄이고, 어긋난 픽셀을 손으로 고치는 정리 과정이 필요하다. 처음부터 픽셀아트 도구(Aseprite, Pixelorama 등)로 직접 그리는 편이 빠를 수도 있다.

## 2. 스탠딩 일러스트

캐릭터의 반신·전신 일러스트. 생성형 이미지로 만든 일반 일러스트 화풍.

| 항목 | 규격 |
|---|---|
| 비율 | 세로 2:3 (예: 1024×1536) |
| 형식 | PNG, 배경 투명 |
| 위치 | `assets/illust/` |
| 파일 이름 | `캐릭터id_portrait.png`, 표정이 여러 개면 `_portrait_angry.png`처럼 |
| 확대 | 일반 보간 사용 (픽셀아트와 반대) |

### 일관성 규칙
- 같은 캐릭터는 같은 기준 이미지(캐릭터 시트)에서 출발해 생성한다.
- 아래 "기준 프롬프트"를 모든 일러스트에 공통으로 붙인다.
- 픽셀아트 캐릭터와 일러스트가 같은 인물로 보이도록 머리색·옷 색·상징물을 맞춘다.

## 3. 글꼴
- 한글 픽셀 글꼴 **Galmuri11** (SIL Open Font License, 무료 사용·배포 가능)
- 받는 곳: GitHub `quiple/galmuri` 저장소의 배포 파일. `Galmuri11.woff2`를 `public/fonts/`에 넣는다.
- 크기·대체 글꼴은 `20-data/ui.json` `font`.
- 라이선스 파일(OFL.txt)도 `public/fonts/`에 함께 넣는다.

## 미결정 사항
- [ ] 픽셀 원본 크기: 16×16 / 24×24 / 32×32
- [ ] 일러스트 화풍 (애니메이션풍, 서양 판타지 일러스트풍, 수채화풍 등)
- [ ] 테마별 팔레트
- [ ] 이미지 생성 도구
